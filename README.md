# AI Personal Fitness Recommendation Platform

## Project Description

AI Personal Fitness Recommendation Platform is a web-based system that provides personalized fitness recommendations based on user profile, fitness goals, physical characteristics, workout preferences, and activity data.

The platform is designed to help users understand their basic fitness requirements and receive simple recommendations for calories, macronutrients, and workouts.

## MVP

The initial Minimum Viable Product includes:

- User profile
- Fitness goal selection
- Basic fitness data input
- Calorie calculation
- Macronutrient calculation
- Basic workout recommendations
- Frontend interface
- Backend API
- Database structure

## Main Features

### User Profile

Users can enter basic personal information:

- Name
- Age
- Height
- Weight
- Activity level

### Fitness Goals

The system supports different fitness goals:

- Weight Loss
- Muscle Gain
- Maintenance

### Calorie Calculation

The platform calculates estimated daily calorie requirements using user information and activity level.

### Macronutrient Calculation

The system provides basic macronutrient recommendations based on the calculated calorie target.

### Workout Recommendations

The platform provides basic workout recommendations according to the selected fitness goal and user activity level.
