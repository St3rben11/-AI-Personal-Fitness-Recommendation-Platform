# Project Proposal

## Project Title

AI Personal Fitness Recommendation Platform

## Project Team

- Arman Amankeldi
- Abzal Bakhtiyarov
- Bakhytzhan Abdilmazhit

## Project Type

Diploma Project

## Problem Statement

Many people want to improve their physical fitness but do not know how to create an appropriate fitness and nutrition plan. Existing fitness applications often provide general recommendations or require users to manually configure complex parameters.

The proposed system aims to provide personalized basic fitness recommendations using information about the user's age, height, weight, activity level, fitness goal, and preferences.

## Target Users

The main target users are:

- Beginner fitness users
- University students
- People starting regular workouts
- Users who need basic calorie and workout recommendations

## Project Goal

The main goal of the project is to develop a web-based platform that analyzes basic user fitness information and generates personalized recommendations for daily calories, macronutrients, and workouts.

## Project Objectives

The project objectives are:

1. Analyze existing fitness recommendation systems.
2. Identify the main requirements of the target users.
3. Design the architecture of the proposed platform.
4. Develop a web-based user interface.
5. Implement a backend API.
6. Design a database structure for storing fitness information.
7. Implement calorie and macronutrient calculations.
8. Implement basic workout recommendations.
9. Test the main system functionality.
10. Evaluate the results against predefined acceptance criteria.

## Expected Results

The expected result is a functional prototype of an AI Personal Fitness Recommendation Platform containing:

- User profile input
- Fitness goal selection
- Activity level selection
- Calorie calculation
- Macronutrient calculation
- Workout recommendations
- Frontend interface
- Backend API
- Database schema
- Testing documentation

## Project Scope

### In Scope

- User fitness profile
- Age, height and weight input
- Activity level selection
- Fitness goal selection
- Daily calorie estimation
- Macronutrient estimation
- Basic workout recommendations
- Web frontend
- Backend REST API
- Relational database structure
- Functional testing

### Out of Scope

The following functionality is not included in the initial prototype:

- Medical diagnosis
- Professional medical advice
- Real-time wearable device integration
- Advanced computer vision
- Real-time exercise pose recognition
- Payment processing
- Social networking features
- Fully autonomous medical or nutritional decision-making

## System Boundaries

The system accepts basic fitness information from a user, processes the information using predefined calculation and recommendation logic, and returns personalized fitness recommendations.

The system is intended as a recommendation and educational tool rather than a replacement for professional medical or fitness advice.

## Technical Complexity

The project combines several engineering components:

- Web frontend development
- Backend API development
- Database design
- Recommendation logic
- Data validation
- Software testing
- System architecture
- User experience design

## Success Criteria

The project will be considered successful when:

1. A user can enter a valid fitness profile.
2. The system validates required input.
3. The system calculates a daily calorie target.
4. The system calculates basic macronutrient recommendations.
5. The system generates a workout recommendation.
6. The frontend displays the generated results.
7. The backend API responds correctly to valid requests.
8. The database schema supports the required entities.
9. The main functional scenarios pass testing.
10. The project documentation describes the architecture, requirements, technologies and verification approach.
